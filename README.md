Takeoff is an online community devoted to holding pundits accountable for their takes.

## Running

To run locally:

```sh
docker compose up -d
pnpm dev
```

## Contributing

This project is meant to exhibit how I use [rngo](https://rngo.dev) to evaluate code I've never read. As such, I'll merge in any code sight unseen, as long as it has a rngo spec.
